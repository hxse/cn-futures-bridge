# 运行环境精简

## 任务边界

仅优化 Xvfb 的三维初始化和截图链路；Wine 使用固定版本的官方预编译包。
保留基础系统、终端版本、中文字体、分辨率、DPI、Openbox、VNC 组件、
配置、账户隔离、队列、API 和交易语义；不整理其他历史镜像或数据卷。
实盘仅允许启动登录及只读查询验证，不创建、发送、撤销交易指令。

交付包括可复用的镜像构建、截图正式链路及对应规范。
兼容性失败阻止采用对应候选，允许恢复该项旧实现并交付其他已验证优化。
不以追求镜像体积引入 Wine 源码编译或继续裁剪未批准的功能。

## 任务规范

Xvfb 禁用 GLX，保留二维 X11、窗口管理和截图；不删除任意运行中 Wine 系统服务。
Wine 仍为 11.0、纯 32 位，使用 WineHQ 签名仓库并校验其密钥哈希。
`wine-stable:i386` 与 `wine-stable-i386:i386` 均固定为 `11.0.0.0~bookworm-1`。
保留官方包及必要依赖，不维护源码构建阶段、源码下载或 Wine 编译脚本。
版本不可获取或校验失败时构建失败，不静默切换其他版本或删除包依赖。
截图及原生桥接工具在独立阶段编译，运行镜像只携带产物。

截图工具只读取 X11 根窗口并编码 RGB PNG，不改变窗口状态或焦点。
诊断截图与失败证据使用同一工具；成功输出完整 PNG，失败返回非零退出码，
调用方沿用 SCREENSHOT_UNAVAILABLE 或现有证据日志处理。
截图仍按需执行，带超时、现有并发保护和工件容量治理。
Openbox 仍需 Imlib2，共用图像库不随 scrot 删除，不扩大为窗口管理器改造。

## 公开接口与用户写法

没有公开接口、配置或命令变化。现有命令继续有效：

```bash
just run
just restart vnc
just screenshot
curl --fail http://127.0.0.1:45173/readyz
curl --fail 'http://127.0.0.1:45173/cfb/fetch_positions?mode=live'
```

截图继续为 PNG；显示服务不存在时明确报错，不返回空图。
环境参数不匹配仍报 ENVIRONMENT_MISMATCH，不切换账户。

## 测试、验证与阶段过渡

正式入口执行 `just check`、`just test`、`just build`。
增加少量离线截图成功及显示不可用检查，原生代码严格编译。
构建期间保留旧镜像作为对照；新镜像通过基本离线启动后才替换默认实例。
临时探针仅放 debug 目录，显式运行，结束后清理本轮探针和临时容器。

用户授权本次在线验证：沿 `just run vnc` / `just restart vnc` 启动，
仅检查真实身份与连接、余额、持仓、委托、成交和交易状态查询，
检查中文显示、PNG、快捷键查询后的焦点恢复与无弹窗 CSV。
在线检查与默认离线 pytest 分开，使用有限超时，异常不无限重试。
同时验证新前缀的空账户启动和既有前缀复用；不以在线只读验证宣称交易发送已回归。

前后使用相同变体、账户、分辨率和查询动作，采样空闲容器内存及关键进程占用，
单独比较镜像大小、截图与查询耗时；不将 RSS 求和或未加载库大小当作容器内存。
验证失败先恢复可用镜像，未确认的候选不保留为并行生产链路。
