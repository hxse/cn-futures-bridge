# 内嵌网页与监控中心窗口

## 任务边界

交付固定 Gecko 资源、启用和注册 MSHTML 的启动链路，以及无标题监控中心的精确识别与自动关闭；同步受影响 current spec。使用当前空 change 承载本子任务，不修改上游历史、README、账户配置或远端书签。

保持 Wine 11.0 预编译包、中文字体、两种镜像的业务等价性、单账户 FIFO、暂停语义、八个业务路由、现有通知模板、未知窗口隔离和工件容量限制。替换原监控中心仅凭标题的识别，不保留更宽松的回退。

不增加浏览器自动登录、网页表单操作、任意网址关闭、通用弹窗点击或新重连机制，不进行任何报撤单。停止线是构建可复现、既有前缀能自动修复 HTML 注册、已识别窗口能有界关闭、未知窗口不误关；远端网页服务不可用不阻断已识别窗口关闭，也不能宣称保证远端页面始终可加载。

## 任务规范

### 镜像与 Wine 初始化

terminal.lock.toml 增加 wine_gecko 锁定项：版本 2.47.4、架构 x86，官方包 https://dl.winehq.org/wine/wine-gecko/2.47.4/wine-gecko-2.47.4-x86.msi，SHA256 为 26cecc47706b091908f7f814bddb074c61beb8063318e9efc5a7f789857793d6。

构建阶段先校验锁定参数，再以有界超时下载，校验散列后提取；校验失败不得继续安装。验证提取目录及 VERSION 后只复制运行资源到 /usr/share/wine/gecko/wine-gecko-2.47.4-x86。提取工具只在构建阶段，headless/vnc 共用该产物；运行阶段不联网下载安装 Gecko。

Runtime 和 NativeClient 的 Wine 环境统一禁用 mscoree，允许默认内置 mshtml。每次 wineboot 成功后，在启动快期之前运行 wine regsvr32 /s mshtml.dll；新前缀仍执行现有中文字体注册。已存在 .bridge-initialized 不得跳过 HTML 注册。注册失败明确阻断启动，返回 HTML_SETUP_FAILED，不带失败状态启动业务。此链路覆盖容器启动和原有终端重连。

### 窗口识别与关闭

保留配置主窗口身份校验；候选必须是同一进程和 GUI 线程拥有的可见顶层 #32770，对应 owner 是配置主窗，具有系统菜单，无 IDOK/IDCANCEL。直接子窗口必须唯一，为可见的 AtlAxWinLic100/1224，且同属进程和线程。

只有持有执行权的显式运行期扫描允许处理候选。通过 WM_ATLGETCONTROL 获取控件的 IUnknown，再查询 IWebBrowser2.LocationURL；及时释放 COM 引用和 BSTR，不记录网址中的查询参数、账户或令牌。普通无弹窗路径不读取 COM，不增加全树扫描或等待。

网址仅允许 HTTPS、精确主机 investorservice.cfmmc.com、缺省端口或 443，以及路径 / 或 /loginByKey.do；允许这两个路径后的查询和片段。拒绝用户信息、近似主机、其他协议/端口/路径、超长或含控制字符的地址。外层标题不参与这一身份判断。

结构正确但尚未得到地址时标记已知浏览器候选等待，沿现有步骤或启动期限轮询；不得自动关闭。地址明确但不在白名单时按未知窗口处理。匹配的监控中心无需等待网页加载或文字渲染，异步发送 WM_CLOSE，并继续检查真实窗口隐藏/消失和主窗可用。

沿用 information_close_count 日志、原通知次数预算、句柄去重及隐藏后状态重置。重复扫描不重复发送关闭，窗口复用后重新验证。不改变其他启动协议、结算单、交易通知和未知窗口的处理规则；pause 后不操作窗口。

## 公开接口与用户写法

八个 /cfb 路由、输入输出、账户配置和运维命令保持不变，无新增公共 API 或开关。用户执行 just restart vnc 或 just restart 更新镜像；以后 podman restart cn-futures-bridge 仍通过同一初始化和检测流程。

例如 GET /cfb/fetch_positions?mode=sandbox 遇到已识别的空标题监控中心时，先关闭并复核，再进入原 CSV 查询。空标题的其他窗口和相似网址仍按未知阻塞返回原有 GUI_RESET_FAILED，不伪造查询成功。网页渲染失败本身不成为订单状态依据。

## 测试、验证与阶段过渡

必需通过 just check、just test、just build。离线 pytest 验证既有前缀仍注册 MSHTML、新前缀保留字体步骤、注册失败阻断，以及 Gecko 散列失败时不提取。沿用既有启动和通知测试，增加无标题候选的等待和关闭计数场景。

原生独立 Wine 窗口夹具在无网络、无账户配置和独立前缀下验证生产识别函数：真实 Win32 owner/控件结构，边界处模拟 IWebBrowser2；覆盖空标题和改标题正例、网址白名单反例、地址未就绪等待、结构或归属不符、重复扫描及句柄隐藏后复用。严格编译原生 helper；夹具和临时产物不进入生产镜像，不给正式工具镜像增加 Wine。

部署到现有 SimNow 容器，仅允许重启、关闭已识别非交易窗口和只读查询。核对现有数据卷的 HTML 注册、组件可见性、自动关闭及重启后的服务就绪；网络不可用时如实报告可验证范围，不反复登录，不做交易验收。

不建立新旧双链或迁移命令。镜像、原生 helper 和 Python 一起更新；不热换正在调用的 DLL，不删除账户前缀或用户数据。发生未解决的构建、离线验证失败或误关风险时不得宣称完成。
