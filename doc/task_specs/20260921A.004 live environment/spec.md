# 实盘环境与单账户绑定

## 任务边界

接入华安期货实盘及严格请求环境匹配。保留已有八个路由、参数默认值、队列、快速提交和独立查询语义；资金仍读原生窗口文字，表格仍无弹窗 CSV，品种状态仍读原生函数。

本任务替代之前“只启用 SimNow”的环境限制，不改变未核验交易分支的能力判定。不增加多账户、双会话、自动切换、额外业务路由或实盘只读限制。AI 的实盘测试授权不成为 API 配置或客户交易权限。

停止线为：环境匹配在 HTTP/准入/执行层生效，两种受控终端种子及账户隔离路径可构建启动，配置及说明可直接指导使用，静态检查和少量离线检查通过。真实华安登录、资金/持仓及交易闭环未完成在线验证时明确说明，不能伪称实盘已成交验证。

## 任务规范

### 配置和唯一来源

bridge.environment 接受 simnow/live，默认 simnow。account 增加 broker_id、site，默认空字符串；simnow 空值解析为 9999/电信2，live 必须明确填写当前支持的 6020 及“一套”或“二套”。环境与券商、站点不匹配在启动前报配置错误，不根据凭证猜环境，不轮流尝试站点。

券商目录来自 terminal.lock.toml 的 profiles，包含环境、券商编号/原名和原生站点列表。构建和配置共用此来源，不从网络动态替换前置或认证。锁定安装包、Wine 和程序文件哈希保持不变；分别生成 simnow/huaan 种子及完整文件清单，验证原包确含声明的券商和站点。

每个实例只载入一个不可变 Settings、一个 runtime 和一个 GUI 执行器。终端、Wine 前缀及账号识别信息位于数据卷的 sessions 子目录，使用环境/券商/站点/账户摘要定位；目录不包含明文密码。旧 /data/terminal、/data/wine 不自动迁移，不覆盖或清空。所有终端诊断日志仍纳入共同预算。

环境切换需要停止容器、修改 TOML、重新启动。重复 run 若配置身份与正在运行容器不符，须明确报错，不能静默复用旧登录；配置身份标签用不包含凭证原文的摘要。默认端口继续使用 45173/45174/45175；不增加全局容器数量锁。

提供 just restart 和 just restart vnc：默认 headless，vnc 显式启用远程桌面。先检查配置并构建选定镜像，再停止、删除本项目同名容器，使用原数据卷和当前配置创建新实例。构建或配置检查失败保留旧容器；不删除数据卷，不操作其他容器，不新增另一套启动链路。just run 仍保留复用规则。

### 环境和会话门禁

请求 mode 保持 sandbox 默认值。simnow 对应 sandbox，live 对应 live；不相等一律返回 409/ENVIRONMENT_MISMATCH，submission_status=null。环境检查先于能力、就绪、幂等重放和入队；HTTP、调度器及独立执行器分别复核，任何 GET/POST 都不能通过改写 mode 切换账户。

实际动作前后核对终端根窗口的券商/站点、配置账户对应的核心身份、连接及交易日。登录只能从新启动的登录窗口发起一次，先确认唯一券商及站点再填凭证；不接管已经由外部登录的未知会话。

登录阶段自动确认已识别的隐私政策和软件使用协议，不逐次询问用户。使用固定标题、原生窗口类、正文控件以及确认/取消按钮身份共同匹配，在终端 GUI 线程内投递对应确认命令；同一窗口不重复点击，确认次数和启动时长有界。确认事件记录到受管日志，完成初始化后关闭此处理。此规则不匹配下单、平仓、撤单、资金划转等业务确认，也不自动处理无法识别的异常窗口。等待主窗及弹窗处理完成后再宣布登录就绪。

首次快速配置向导按固定窗口及控件身份自动取消，保留默认界面。启动窗口快照调用的期限使用剩余启动时长，避免把客户端初始化按业务步骤短超时误判；启动结束后恢复原业务步骤期限。

主窗出现不等于柜台初始化完成。剩余启动时限内只读等待账户身份与交易/行情连接就绪，期间不重登；登录代次变化时拒绝绑定。此等待结束后才能建立执行器账户身份。

原生 helper 以受控配置传入的主窗口身份替代固定 SimNow 字样，仍校验固定程序和核心哈希。监视登录窗口重新创建/显示/激活的代次；初次成功登录后再出现登录界面时，原身份授权失效，暂停直到重启容器，不能仅因为旧 GetUser 缓存可访问而恢复。品种状态请求的身份检查不切页或按键。

live 开放与当前适配一致的交易及查询路径，不因实盘返回只读错误；市价、IOC/FOK、指定平今/平昨等未核验分支仍在副作用前拒绝。幂等命名空间包含环境、券商和账户；恢复及未决计数按该命名空间处理，不返回另一环境的旧结果。

### 身份与取证

日志只记录环境、券商、站点及脱敏信息。原生登录输入、账户摘要前的原文、完整配置和密码不输出。状态增加当前 request_mode、broker_id、site，保留已有字段和语义；未配置账户不能宣布登录或交易就绪。

## 公开接口与用户写法

已有 SimNow 配置继续有效；显式写法：

```toml
[bridge]
environment = "simnow"

[account]
broker_id = "9999"
site = "电信2"
username = "你的模拟账号"
password = "你的模拟登录密码"
```

华安实盘配置，替换对应两个节，其余端口、日志和执行配置保留：

```toml
[bridge]
environment = "live"

[account]
broker_id = "6020"
site = "一套"
username = "你的华安资金账号"
password = "你的快期登录密码"
```

site 应与用户实际可登录站点一致，另一个允许值是“二套”；不自动回退。没有 read_only 字段。凭证仅由用户填写到本地文件，不纳入版本控制。

```bash
just restart vnc
curl 'http://127.0.0.1:45173/cfb/fetch_balance?mode=live'
curl 'http://127.0.0.1:45173/cfb/fetch_positions?mode=live'
```

在实盘实例省略 mode，或显式传 sandbox，返回 409/ENVIRONMENT_MISMATCH；模拟实例传 live 同样返回 409。实盘下单仍是现有 POST 请求加 mode=live，用户自主操作；本任务不执行实盘交易样例。

## 测试、验证与阶段过渡

主检查为宿主 just check。just test 仅增加必要离线用例：两个方向的环境冲突、实盘省略 mode、合法 live 查询及限价请求能够到达就绪检查、模拟默认配置兼容、无效券商/站点、账户目录及幂等命名空间隔离。复用原测试，不新增在线交易套件。

初始化身份等待的离线检查覆盖主窗先出现、交易身份后就绪的正常顺序，以及等待期间登录代次变化被明确拒绝，不弱化最终账户绑定。

just build 严格编译原生 helper 并构建两种镜像；无账户、断网、独立临时数据验证两种环境的终端配置和控制器启动，不替换用户正在运行的实例。只读元数据检查可读取原包券商/站点，不输出认证参数或凭证。

restart 入口使用少量离线 pytest，模拟 Podman 验证构建先于停止、停止删除先于启动、headless/vnc 选择，以及配置/构建失败和非受管容器不会被停止。在线验证独立于 just test：用户明确授权后运行 just restart，等待有限时间确认登录，再 GET 查询 live 资金及持仓；不调用下单、撤单、平仓或预埋单写入。

启动确认使用无账户、断网的原生窗口夹具，核对已识别政策窗口会投递一次确认；交易标题、错误控件、禁用按钮、非启动阶段及超期不确认。真实首次登录核对确认日志、弹窗退出及账户只读查询，不能把窗口夹具视为交易功能验证。

同步 current spec、README 和配置示例，移除现行文档中仅支持模拟及强制只读的表述。实盘登录或交易未经在线核验的边界应明确保留；AI 后续实盘交易测试仍需用户明确授权，不能沿用模拟盘测试授权。
