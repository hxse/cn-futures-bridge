# 结算单自动确认

## 使用场景与设计初衷

用户的 SimNow 登录被“确认结算单”弹窗阻塞，希望程序精确识别并自动确认。
结算窗口可能在主窗口出现、账户连接乃至启动完成后到达，不能只依赖启动事件。
用户授权自动确认结算单，本任务不创建、发送或撤销交易指令。

## 方案对比

像素定位或通用 Enter 无法区分结算确认和交易确认。
固定版本提供原生窗口、控件编号、只读正文和明确按钮，可以逐项核对。
仅依赖窗口显示事件会漏掉正文或按钮尚未就绪的情况，须由启动窗口读取补充检查。

## 取舍结论

扩展既有文档确认流程，保留同一 GUI 线程和有界执行权。
使用精确窗口特征及正文标识，不输出结算明细，不增加通用弹窗确认器。
启动结束后只有执行器的界面基线检查可确认结算单，复用既有空闲探测和请求队列。
普通窗口回调不在运行期自动点击，暂停成功后不再探测或点击；未知弹窗继续阻断执行。
